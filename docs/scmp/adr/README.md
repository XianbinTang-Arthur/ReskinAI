# ADR Index

This folder stores Architecture Decision Records (ADR) for ReSkin AI.

## Naming

Use: `ADR-XXXX-short-title.md`

Examples:
- `ADR-0001-model-hosting-strategy.md`
- `ADR-0002-image-storage-encryption.md`
- `ADR-0003-artist-portal-service-boundary.md`

## Rules

- Start with status `Proposed` and update to `Accepted` after decision.
- Do not delete superseded ADRs. Mark them as `Superseded` and link replacement ADR.
- Link each ADR to related issue or change request.
