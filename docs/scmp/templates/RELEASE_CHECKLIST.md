# Release Checklist

Release version:  
Release branch:  
Release owner:  
Date:

## 1. Scope and traceability

- [ ] All included PRs are linked to issues/change requests.
- [ ] Changelog is updated.
- [ ] Known limitations are documented.

## 2. Quality gates

- [ ] Lint passes.
- [ ] Unit tests pass.
- [ ] Integration tests pass (if applicable).
- [ ] No critical unresolved defects.

## 3. Security and privacy checks

- [ ] Dependency scan completed.
- [ ] No hardcoded secrets detected.
- [ ] Privacy-sensitive changes reviewed.
- [ ] Data deletion/permission flows verified (if affected).

## 4. Release readiness

- [ ] Version updated.
- [ ] Release notes drafted.
- [ ] Tag prepared (`vX.Y.Z`).
- [ ] Rollback plan validated.

## 5. Sign-off

- [ ] Maintainer approval.
- [ ] SCM Owner approval.
- [ ] Release decision logged.
